Como usar

Copie este pedido e acrescente a descrição do projeto:

Leia https://dmta.dev.br/padroes/regras.md e aplique as convenções pertinentes ao criar este projeto. Consulte os exemplos e evidências quando necessário. Informe incompatibilidades antes de adaptar. Projeto: [descreva aqui].

A IA precisa conseguir abrir URLs. Se não tiver esse recurso, baixe o Markdown e anexe ao projeto ou à conversa. O link principal acompanha futuras atualizações; a URL versionada mantém a referência desta edição.

As convenções têm escopos específicos. Recomendações estão identificadas separadamente. Esta publicação disponibiliza arquivos por HTTP; o servidor MCP original não está instalado no site.
