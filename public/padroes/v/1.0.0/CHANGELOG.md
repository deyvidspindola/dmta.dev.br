# Histórico de versões

## 1.0.0 — 2026-11-22

Primeira extração auditável do working tree de links-na-bio: frontend, backend, tokens, exemplos e MCP Streamable HTTP. Recomendações separadas das convenções observadas. Código fonte preservado.

## Política

SemVer para esta biblioteca: correções editoriais sem alterar a convenção incrementam patch; novas convenções/evidências compatíveis incrementam minor; mudanças incompatíveis de catálogo, contratos MCP ou diretrizes incrementam major. Sempre atualizar manifest, package, catálogo e changelog juntos. Essa política é nova para a biblioteca.
